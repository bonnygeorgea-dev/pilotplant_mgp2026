📊 Google Sheets Integration
Connect this tool to a Google Sheet to sync FG Inventory, Sales, Transaction Log and Material Balance bidirectionally. The sheet acts as your persistent database — data survives browser refresh. Follow the steps below to set up the Apps Script web app endpoint.
STEP 01
Use your Google Sheet with these tabs:
FG_Stock, Sale_Log, Transaction_Log, Material_Balance
The script can create missing tabs automatically on the first verified Push.
STEP 02
In the Sheet, go to Extensions → Apps Script. Paste the Apps Script code shown below. Save and Deploy as Web App → Anyone with the link → Execute as Me.
STEP 03
Copy the Web App deployment URL and paste it in the field below. Click "Connect & Test".
STEP 04
After opening the app on any computer, go to Settings and Pull All Data first. When work is finished, use Push All Data. A stale computer is blocked from overwriting a newer shared revision.
📊 Open Google Sheet
⚠ How syncing works: All entries save to your browser instantly. Syncing with Google Sheets is fully manual — no automatic background sync.

Recommended routine:
• First time on a new browser / GitHub URL → Pull is mandatory before Push.
• When you start → click Pull from Sheets to get the latest data (from the other computer).
• When you finish → click Push to Sheets to save FG Inventory, Sales, Transaction Log and Material Balance so the other computer can see them.

Multi-computer protection: every successful Push creates a new shared revision. If another computer has already pushed a newer revision, your Push is blocked automatically. Pull the latest revision first, review it, then make/re-enter your change and Push.
